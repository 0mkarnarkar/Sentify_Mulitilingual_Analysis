PROJECT NAME: SENTIFY - MULTILINGUAL NEURAL ANALYTICS ENGINE
===========================================================================

1. PROJECT OVERVIEW
---------------------------------------------------------------------------
Sentify is a high-performance, Enterprise-Grade NLP (Natural Language 
Processing) application designed to transform unstructured multilingual 
text into actionable business intelligence. 

The system acts as a "Neural Pipeline" that identifies, translates, 
categorizes, and visualizes emotional data in 3D space.

2. CORE CAPABILITIES
---------------------------------------------------------------------------
* UNIVERSAL INGESTION: Accepts data via Live Console (Single Text), 
    CSV, JSON, and raw TXT (line-by-line) files.
* AUTO-LANGUAGE DETECTION: Identifies 130+ languages (Hindi, Marathi, 
    Spanish, French, etc.) using statistical linguistic profiles.
* NEURAL TRANSLATION: Standardizes all regional inputs into English 
    using a Google-backed translation API for consistent scoring.
* DUAL-METRIC ANALYTICS: Calculates mathematical scores for:
    - POLARITY: Emotional tone (-1.0 Negative to +1.0 Positive).
    - SUBJECTIVITY: Data type (0.0 Fact to 1.0 Personal Opinion).
* 3D NEURAL CLUSTERING: Visualizes data points across three axes 
    (Polarity, Subjectivity, and Word Count) using interactive Plotly 
    3D scatter plots.
* PORTABLE REPORTING: Generates a standalone Interactive HTML Report 
    with embedded 3D models and distribution charts (Pie/Bar).

3. THE TECHNOLOGY STACK (UNDER THE HOOD)
---------------------------------------------------------------------------
* CORE LANGUAGE: Python 3.13
* UI FRAMEWORK: Streamlit (With custom Glassmorphism/Dark Mode CSS)
* TRANSLATION: Deep-Translator (Google NMT API)
* DETECTION: Langdetect (Statistical Language Identification)
* NLP BRAIN: TextBlob (Lexicon-based Sentiment Algorithm)
* VISUALIZATION: Plotly (High-performance 3D Rendering)
* DATA HANDLING: Pandas (High-speed Dataframes)

4. ADVANCED ARCHITECTURE FEATURES
---------------------------------------------------------------------------
* SMART QUEUE LOAD BALANCER:
    Unlike standard student projects, Sentify uses a "Batch Processor 
    Queue." It breaks large datasets into small chunks, preventing API 
    throttling and ensuring the system remains stable during heavy 
    data ingestion.

* SPATIAL DATA TOPOLOGY:
    By mapping "Subjectivity" on a 3D axis, the system helps analysts 
    distinguish between "Objective Complaints" (Facts) and 
    "Subjective Vents" (Opinions), which is critical for real-world 
    customer support.

5. REAL-WORLD USE CASE (AMAZON / UBER)
---------------------------------------------------------------------------
* SCENARIO: A company like Uber receives 10,000 mixed-language 
    reviews.
* PROCESS: Sentify ingests the data, translates it, and clusters it.
* INSIGHT: The 3D map shows a cluster of Negative reviews with 
    LOW SUBJECTIVITY.
* ACTION: Management realizes these are factual reports of a technical 
    bug (e.g., "App crashed during payment") rather than just rude 
    complaints, allowing for an immediate engineering fix.

* SOFTWARE: Python 3.x, Chrome/Edge/Safari Browser.
* LIBRARIES: streamlit, pandas, plotly, textblob, deep-translator, 
    langdetect.
